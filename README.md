# Linux System Administrator Portfolio — Pranjal Bisht

A high-performance, dark-themed, interactive portfolio website tailored for Linux System Administrators, SREs, and DevOps Engineers.

---

## 🚀 Key Features

- **Interactive Linux Terminal Simulator**: Run commands like `help`, `whoami`, `uptime`, `uname -a`, `skills`, `experience`, `projects`, `certs`, `education`, `contact`, `neofetch`, or click quick shortcut chips.
- **Telemetry & Live Status Badges**: High-availability metrics and live SLA uptime counters (99.9%).
- **Skills Matrix**: Categorized competencies across Operating Systems (RHEL 8/9, CentOS, SUSE), Automation & Scripting (Ansible, Bash), Storage & Virtualization (LVM, VMware vSphere, NetWorker), and Troubleshooting/Security (top, iostat, vmstat, netstat, dmesg, ServiceNow ITSM).
- **Filterable Projects Grid**: Category filters for Automation, OS Upgrades & Migration, Storage & LVM, and Diagnostics & RCA.
- **Verified Certifications Section**: Highlighting RHCSA (EX200), Azure Fundamentals (AZ-900), and Azure (AZ-104).
- **Career Journey Timeline**: Complete 13-point enterprise experience at Tata Consultancy Services (TCS).
- **Dark / Light Mode Toggle**: Smooth theme transition with local storage persistence.
- **Zero-Dependency Architecture**: Built with modern semantic HTML5, Vanilla CSS, and JavaScript. Zero build steps, instant load time, 100% SEO & mobile responsive.
